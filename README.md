## :dart: O guia para alavancar a sua carreira

> Java é uma das linguagens mais usadas no mundo corporativo: bancos, seguradoras, varejo, governo e boa parte das grandes empresas brasileiras rodam sistemas em Java, e o ecossistema Spring domina as vagas de back-end no país. Criada em 1995, a linguagem segue viva e em evolução — hoje com ciclos de lançamento previsíveis a cada seis meses, versões LTS de longo suporte (17, 21, 25) e recursos modernos como records, pattern matching e virtual threads. Este guia reúne roadmap, cursos, documentação, livros, canais, ferramentas, projetos práticos e comunidades para quem está começando do zero até quem já programa e quer aprofundar Java e Spring. Os recursos em português e gratuitos vêm primeiro em cada seção, e todo link foi verificado. Use-o como apoio para os seus estudos, no seu ritmo, e não como uma lista que precisa ser vencida de uma vez.

## 🗺️ Roadmap

- [roadmap.sh — Java Roadmap](https://roadmap.sh/java) — Roadmap visual e interativo da comunidade: o que estudar, em que ordem, com links por tópico.
- [roadmap.sh — Spring Boot Roadmap](https://roadmap.sh/spring-boot) — O caminho para dominar o Spring Boot depois da base de Java.
- [Dev.java — Learn](https://dev.java/learn/) — Portal oficial da Oracle para aprender Java, com trilhas por nível e tópico.
- [java-developer-roadmap (s4kibs4mi)](https://github.com/s4kibs4mi/java-developer-roadmap) — Roadmap da comunidade no GitHub, atualizado para 2026, com o que estudar em cada etapa.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Base** — o que é a JVM (Java Virtual Machine), instalação do JDK, `javac`/`java` na linha de comando, o primeiro `Hello World`.
2. **Sintaxe e lógica** — variáveis, tipos primitivos, operadores, condicionais, laços, arrays e métodos.
3. **Orientação a objetos** — classes, objetos, atributos, construtores, encapsulamento, herança, polimorfismo, interfaces e classes abstratas.
4. **Coleções e genéricos** — `List`, `Set`, `Map`, `Collections`, generics e o básico de streams (`java.util.stream`).
5. **Tratamento de erros e I/O** — exceções checked/unchecked, `try-with-resources`, leitura e escrita de arquivos.
6. **Java moderno** — lambdas, streams, `Optional`, records, pattern matching, sealed classes e virtual threads (a partir do Java 21).
7. **Ecossistema** — Maven ou Gradle, JUnit 5 para testes, Git, e uma IDE (IntelliJ IDEA ou Eclipse).
8. **Persistência e web** — JDBC, JPA/Hibernate e o framework Spring (Spring Boot) para construir APIs REST.
9. **Aplicação** — um projeto completo com Spring Boot, banco de dados, testes automatizados e deploy.

**Por onde começar:**

1. **Instale o ambiente:** um [JDK LTS atual](https://adoptium.net/) (17, 21 ou mais recente) e uma IDE como o [IntelliJ IDEA](https://www.jetbrains.com/idea/) (edição Community é gratuita).
2. **Entenda o panorama da linguagem** no [Dev.java — Learn](https://dev.java/learn/), o portal oficial da Oracle para aprender Java.
3. **Faça um curso completo em português:** o [Curso de Java para Iniciantes (Curso em Vídeo)](https://www.youtube.com/playlist?list=PLHz_AreHm4dkI2ZdjTwZA4mPMxWTfNSpR), seguido do [curso de POO com Java](https://www.youtube.com/playlist?list=PLHz_AreHm4dkqe2aR0tQK74m8SFe-aGsY).
4. **Pratique a sintaxe** com o [Java Full Course for Beginners (Programming with Mosh)](https://www.youtube.com/watch?v=eIrMbAQSU34) ou o livro gratuito [Think Java](https://greenteapress.com/wp/think-java-2e/).
5. **Aprofunde orientação a objetos** estudando o repositório [java-design-patterns](https://github.com/iluwatar/java-design-patterns), com dezenas de padrões de projeto comentados.
6. **Construa e teste um projeto pequeno** com [Maven](https://maven.apache.org/) ou [Gradle](https://gradle.org/) e testes em [JUnit 5](https://junit.org/junit5/).
7. **Dê o salto para o back-end** com a [documentação oficial do Spring Boot](https://docs.spring.io/spring-boot/index.html) — o framework mais pedido em vagas Java no Brasil.
8. **Publique um projeto no GitHub** e participe da comunidade [SouJava](https://soujava.org.br/), o maior grupo de usuários Java do mundo, sediado no Brasil.

Seu primeiro programa em 30 segundos:

```bash
mkdir ola-java && cd ola-java
java --version        # confirme que o JDK está instalado
```

```java
// Ola.java
public class Ola {
    public static void main(String[] args) {
        System.out.println("Olá, Guia Dev Brasil!");
    }
}
```

```bash
java Ola.java          # Java 11+ compila e executa em um único passo, sem javac manual
```

## 🤖 IA na prática

Java é uma linguagem verbosa e fortemente tipada — isso ajuda bastante quando se usa IA para programar, porque o compilador e a IDE pegam boa parte dos erros que a IA comete. Ainda assim, é preciso revisar com atenção.

**Para aprender**
- Cole uma `StackTraceException` inteira (ex.: `NullPointerException` ou `ClassCastException`) junto com o trecho de código e peça: *"explique a causa raiz e mostre duas formas de corrigir"*.
- Peça para **explicar um conceito com um exemplo compilável**: herança vs. composição, `equals`/`hashCode`, streams, virtual threads. Rode o exemplo você mesmo para confirmar.
- Peça **exercícios com gabarito** sobre o tópico que está estudando (coleções, generics, exceções) e resolva antes de olhar a resposta.
- Peça para reescrever um código seu que usa `for` tradicional e classes anônimas em **Java moderno** (streams, lambdas, records) e explicar cada mudança.

**Para trabalhar**
- Use [GitHub Copilot](https://docs.github.com/pt/copilot), o [JetBrains AI Assistant](https://www.jetbrains.com/ai/) (integrado ao IntelliJ) ou o [Claude Code](https://code.claude.com/docs/en/overview) para: gerar testes com JUnit 5, escrever DTOs e mappers repetitivos, migrar código legado para records/streams e revisar pull requests.
- Depois de **cada** sugestão aceita, compile e rode os testes (`mvn test` ou `./gradlew test`). Se a IA sugeriu uma dependência, confira se ela existe e é mantida antes de adicionar ao `pom.xml`/`build.gradle`.
- Peça sempre a versão-alvo: "Java 21, Spring Boot 3". Sem isso a IA mistura APIs antigas (`java.util.Date`) com as modernas (`java.time`).

**Limites e boas práticas**
- A IA **inventa métodos e classes** que não existem na API padrão, e confunde versões diferentes do Spring. Confirme sempre na [documentação oficial do Java](https://docs.oracle.com/en/java/) e do [Spring](https://docs.spring.io/spring-framework/reference/).
- Ela tende a ignorar tratamento de exceções e casos de borda (`null`, coleção vazia). Peça explicitamente por tratamento de erros e por testes de casos limite.
- Cuidado com sugestões de concatenar SQL diretamente (SQL Injection) em vez de usar `PreparedStatement`/JPA — a IA ainda sugere isso com frequência.
- Não cole código proprietário, segredos (`application.properties`, tokens) ou dados de clientes em ferramentas sem a política da sua empresa.
- Entenda o que você aceita: em entrevista e em produção, o código é seu.

**O ecossistema Java também está entrando na IA generativa**, com bibliotecas próprias para construir aplicações com LLMs:
- [Spring AI — documentação](https://docs.spring.io/spring-ai/reference/) — projeto oficial do Spring para integrar aplicações Java com modelos de IA, RAG e agentes.
- [LangChain4j](https://github.com/langchain4j/langchain4j) — biblioteca Java open source para LLMs: RAG, tool calling e agentes, com integração a Spring Boot e Quarkus.
- [Gemini Code Assist](https://codeassist.google/) — assistente de código do Google para VS Code e JetBrains, com plano gratuito.
